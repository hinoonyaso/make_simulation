# Discovery pass

Use only for finding/shortlisting papers.

- Search primary indexes/publisher/project pages with the user's exact mechanism/task terms; record search date, queries and scope.
- Resolve ambiguous names before ranking candidates.
- For each candidate keep: identity/version, one-sentence contribution, mechanism visibility, code/checkpoint availability, hardware/experiment feasibility, and primary URL.
- Prefer relevance + inspectable mechanism + reproducible evidence over popularity/demo polish.
- Revision date is not the same as original publication date. Do not imply exhaustive coverage.
- Check licenses before proposing redistribution; do not download large checkpoints just to shortlist.

Output a compact shortlist, then deep-read only the selected candidates.
