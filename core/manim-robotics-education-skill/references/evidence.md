# Evidence / Trace Rules

Allowed labels:
- **Illustration**: conceptual animation; not numerical evidence.
- **Toy simulation**: explicit simplified model with stated assumptions.
- **Model execution**: output produced by an actual model/runtime.
- **Measured trace**: recorded data from a real or simulated system.
- **Reported paper result**: value taken from a cited source.

Never fabricate curves or benchmark numbers to make an animation look convincing. If Manim and Blender show the same values, load one shared trace/config and derive labels/plots from it.
