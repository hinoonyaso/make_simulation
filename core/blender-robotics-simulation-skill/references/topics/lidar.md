# LiDAR
Sensor origin + scan plane + curve rays. If claiming simulated scan, compute intersections/ranges from geometry/backend; otherwise label rays illustrative. Distinguish hit/no-hit/range limit; connect output to map/localization.

Use `templates/robotics_visual_utils.py::add_lidar_scan(name, origin, ranges, angle_min, angle_increment, range_max)` to draw the scan from precomputed samples (sensor_msgs/LaserScan convention). It never invents ranges and auto-colors hit/no-hit/range-limit per the rule above. For a concrete robot's lidar housing (not just an abstract sensor), import `assets/jetrover/meshes/sensors/lidar_link.stl` — registry id `blender.jetrover.sensors.v1`. For an episode about a specific commercial sensor rather than JetRover's onboard unit, use `blender.livox_mid360.v1` (also ships a FOV-envelope mesh, useful for showing scan coverage) or `blender.ouster_os1.v1` / `blender.ouster_os0.v1` / `blender.ouster_osdome.v1` — these are STEP, not STL, so convert via FreeCAD first.
