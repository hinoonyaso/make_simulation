# Depth -> XYZ
Keep camera center, image plane/pixel ray, depth plane, and point P visually persistent. Reveal ray first, then depth intersection, then camera-frame coordinates. Use orthographic inset only when it clarifies similar triangles.

For a concrete depth camera housing (not just an abstract camera icon), use `blender.realsense_d435.v1` or `blender.zed2i.v1` — both STEP, convert via FreeCAD first.
