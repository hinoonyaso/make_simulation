# Shared Visual Contract

Keep these consistent across Manim and Blender:
- variable names, units, coordinate-frame names, timestamps;
- X/Y/Z = red/green/blue only for axes;
- sensor/camera = cyan-blue;
- active quantity = amber/yellow;
- valid/result = green;
- error/invalid = red;
- learned/latent representation = violet;
- inactive context = neutral gray.

Use a restrained dark-neutral or light-neutral background, not decorative gradients. One frame should usually have no more than two strong accent colors besides axes.
