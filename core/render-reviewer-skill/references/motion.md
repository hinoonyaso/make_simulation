# Motion review
Flag motion only when it harms explanation:
- narration and visual event disagree in time;
- camera, object and equation change compete simultaneously;
- important reveal finishes before it is spoken;
- equation/geometry disappears before inspection;
- static dead time has no comprehension purpose.
Patch by sequencing events, retiming one owner, or removing redundant motion.

For the central explanation, inspect before/during/after the spoken causal phrase. Distinguish physical presence, detection, map update, plan selection and execution where relevant. A path appearing after the robot follows it can invert the teaching sequence even if trace poses are correct.

Inspect padded time against the visual task. A static comparison can be purposeful; continuous camera motion does not make unexplained waiting purposeful. Report the exact interval and what understanding is lost. Do not infer audio silence from subtitle absence alone.

## Moving excerpt and listening record

Record the actual media file/version and inspected start/end ranges. Watch the decisive change at normal speed with narration; check whether evidence appears before the conclusion and whether camera, labels and object movement compete. Listen for pronunciation, unnatural phrase boundaries, rushed discovery and irrelevant silence. Rewatch the smallest unclear span; use stills and measured cue timings to locate the problem.

Ask what changes under a stated new condition only when the shown mechanism supports a prediction. “Insufficient evidence to determine a unique optimum” can be the correct answer. Log the initial interpretation before reading the trace; distinguish self-review from independent viewer feedback.

If playback or audio is inaccessible, retain the frame/timing findings but mark the corresponding inspection incomplete. Do not equate a generated excerpt, audio stream presence, successful decode or a clean waveform with actual watching/listening.
