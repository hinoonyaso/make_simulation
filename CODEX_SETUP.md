# Codex setup

1. Put this bundle at the project root or run Codex from this directory.
2. Trust the project so `.codex/config.toml` is loaded.
3. Existing user-level MCP config (including `davinci-resolve`) remains inherited.
4. Use `/status` to verify the project model/config.

The Lite bundle intentionally has fewer agents. Missing `narration`, `asset_library`, or `reviewer_deep` roles is expected.
