# Costmap Inflation — 장애물 주변 비용장

Final: `output/costmap_inflation_ko.mp4` (target 1920×1080, 30 fps, Korean narration and sentence captions, 60–90 seconds).

## Decision basis

- The preceding videos introduced a global grid path and a DWB-style short-horizon choice. This episode explains a supporting idea: obstacle proximity becomes a graded map cost, so a route can account for clearance before it reaches a collision cell.
- We use the static `topics/08_nav2` model trace because its saved grid, obstacle geometry and baseline path show this idea in one consistent coordinate system. The existing studio TurtleBot3/drum clip opens with a physical question; it is illustrative context and does not claim the map geometry was measured from that footage.
- The map is a 41×61 matrix at 0.15 m resolution. In the source model, `d` is clearance to modeled static boundaries. Cells where `d <= robot_radius + 0.22 m` are assigned 255; for `d < 1.0 m`, other costs use `180 * exp(-3.5 * max(d - 0.25, 0))`; farther costs are zero. The 255 assignment overrides the exponential value. The first baseline path is shown from the same saved trace.
- The recorded map and path are played back. The color reveal between snapshots is a rendering tween, not a new costmap computation. We chose Manim because the lesson is a 2D numeric field and a traced path; Blender depth would not improve this explanation.

## Data boundary and evidence

`extract_trace.py` reads `topics/08_nav2/output/trace.json` without modifying it. It copies only `static_costmap`, map axes/resolution, robot radius, modeled obstacle boxes, and `baseline.plans[0].path` into `data/costmap_trace.json`. It excludes the dynamic-person scenario, scans, controller candidates, and other simulation rows. The converted V9 trace is checked with `core/shared-data/validate_trace.py`.

This is a **custom educational model**, not a Nav2 costmap plugin execution or a reproduction of Nav2's inflation layer. Values describe the source model only. The physical studio footage is separately labeled as illustration.

## Director, local helpers and kit/skill findings

- `visual_manifest.json` is the single beat contract for Korean narration, measured timing, captions and media ranges. Its five computation beats keep one costmap and progressively reveal lethal cells, graded costs, then the recorded path.
- The Manim kit provides palette, timing and scene primitives but has no trace-matrix-to-costmap heatmap primitive. `heat_image()` is pilot-local: it converts the exact saved numeric matrix into a transparent raster with threshold/gradient modes. If this representation is reused, a V9-aware costmap heatmap helper with declared value range and palette would be a kit candidate. The kit was not changed.
- The Director/Manim guidance says to use real computed state and permits tweening between saved states, but it does not prescribe how to label a visualization-only interpolation of a static trace. This episode labels the evidence as trace playback and documents the color tween here. A concise convention for “trace playback with display-only tween” could clarify future episodes.
- `sox` is absent in the environment; Manim emitted its warning, but the scene does not use Manim voiceover. Narration and captions were generated by the shared pipeline.
