# R10 렌더 실험과 두 채널 비교

## 비교 방법과 한계

이번 비교는 채널 전체의 순위 평가가 아니다. 아래 두 영상에서 실제 공개 storyboard 프레임을 확인하고, R10의 대응하는 설명 구간과 비교한다. 참고 영상은 320×180 프레임을 5초/10초 간격으로 제공한다. 프레임은 실제 영상의 샘플이지만 연속 재생·청취가 아니므로 컷 리듬, 움직임의 매끄러움, 내레이션 자연스러움과 미세한 재질 품질은 판단하지 않는다. 공개 timedtext 응답이 비어 자막 원문도 확보하지 못했다. 브라우저의 watch 페이지 접근 실패를 직접 공개 페이지/이미지 접근으로 보완했으며 로그인·쿠키는 사용하지 않았다.

| 참고 영상 | 길이 | 실제 확인한 샘플 구간 |
|---|---:|---|
| [bRd 3D: 드론은 어떻게 작동할까?](https://www.youtube.com/watch?v=d7RfB4Gf02Y) | 8:54 | 0–40, 45–85, 90–130, 180–220, 270–310초; 5초 간격 |

샘플과 메타데이터는 Git 제외 `output/references/`에 둔다. 원본 영상 파일은 내려받지 않았다. 경사하강법의 개념 순서는 [3Blue1Brown 공식 원문](https://www.3blue1brown.com/lessons/gradient-descent/)으로 교차 확인했다. 원문은 한국어 채널의 음성·편집을 검증하는 자료가 아니다.

## 이번 실험의 판단

설명 연결과 원형 소품의 표면 품질은 개선 방향이 명확하다. 다만 이 두 변경은 국소 개선이며 두 참고 영상의 표현 깊이 전체를 확보한 것은 아니다. 현재 범위에서 확인되지 않은 정상 속도 리듬·음성·초심자 이해를 점수로 바꾸거나 ‘동급’이라고 단정하지 않는다.

다음 제작에서 가장 효과가 큰 보완은 **방향 오차→좌우 바퀴 명령→바닥 접점의 힘→몸의 회전**을 같은 순간에 연결하는 한 장면이다. 명령/힘은 실제 데이터에 있는 값과 교육용 도식을 구분해야 한다. 이후 같은 위치에서 목표 방향만 바꾼 조건을 실제로 실행하면, 지금의 가정 그림을 관측 가능한 비교로 발전시킬 수 있다. 이 제안은 이번 렌더 실험에 새 물리 실행을 끼워 넣었다는 뜻이 아니다.

## R09 대비 실험 통제

- 물리 데이터·충돌 형상·로봇 STL·카메라·조명은 동일하다.
- 대본 B03/B05를 바꾸어 새 길의 한계와 실제 응답 확인을 연결했다. 재생성한 음성에 맞춰 문장 자막과 B05 목표 컷을 재정렬했다.
- 드럼 cylinder/torus와 목표 ring의 렌더 분할 수만 로컬에서 높였다. 크기·위치는 동일하다.
- 표면 후보는 타이밍 변경 전에 같은 source pose/camera로 비교했다. 최종 영상의 같은 재생 초는 음성 타이밍 변경 때문에 같은 solver 상태를 뜻하지 않을 수 있다. `surface_candidate_mapping.json`과 각 버전 `source_mapping.json`을 사용한다.
- 최종 기술 게이트와 실제 합성 프레임 검토 결과는 README와 `output/final_review.json`에 기록한다. 기술 PASS가 채널 동급 판정을 대신하지 않는다.

기존 실행의 검증 수치도 보존했다. ON의 최종 목표 오차는 약 0.112m(기준 0.15m 이내), 보수적 proxy 최소 여유는 약 0.231m(기준 0.10m 이상)이다. OFF는 목표 오차 약 1.667m이며 드럼 접촉으로 멈춘다. repeat 위치 차이 0, fine step ON 종점 차이 약 0.048m를 기존 probe 기준으로 확인했다. 이는 해당 교육용 실행의 검증이며 시간 간격 수렴이나 실제 로봇 성능 검증은 아니다. R10에서 좋아진 회피 성능이라는 주장에도 사용하지 않는다(`output/run_review.json`).
