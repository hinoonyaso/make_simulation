## 새 물리 계산의 근거와 한계

- `physics_cases.py`가 로컬 Bullet 모터 힌지로 바퀴를 구동한다. 몸체 위치를 경로 위로 지정하지 않는다. 30 Hz, 6초, 최초 0.5초는 안정화 구간이다.
