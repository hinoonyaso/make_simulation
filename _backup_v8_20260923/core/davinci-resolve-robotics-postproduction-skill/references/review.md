# Post-production review

Use this after the first complete preview, not before assembly.

## Pass 1 — Story
- Is the central question obvious early?
- Does every beat causally lead to the next?
- Can any beat be removed without losing understanding? If yes, consider removing it.

## Pass 2 — Visual
- One dominant attention target per beat.
- Avoid editor-added zoom when source animation already guides attention.
- Check text safe areas, equation dwell time, occlusion, and Manim/Blender style continuity.

## Pass 3 — Motion
- Remove dead air that adds no thinking time.
- Preserve deliberate pauses where the viewer must inspect geometry/equations.
- Avoid simultaneous camera move + text reveal + graph change unless intentionally staged.

## Pass 4 — Audio
- Narration is always understandable.
- SFX are sparse and semantically motivated.
- BGM supports pacing but disappears perceptually during difficult explanations.

## Pass 5 — Technical
- Correct project/timeline frame rate and resolution.
- No offline media, gaps, accidental black frames, clipped audio, or duplicate subtitles.
- Validate render configuration before queueing final output.
