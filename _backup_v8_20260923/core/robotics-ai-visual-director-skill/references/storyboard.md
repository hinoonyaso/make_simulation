# Storyboard Grammar

Use 6–12 beats for a 60–120 s explainer.

Each beat answers one of these jobs:
- **Hook**: create a precise puzzle, not generic hype.
- **Failure**: show why the naive intuition breaks.
- **Intuition**: animate the hidden relationship before naming it formally.
- **Mechanism**: show what changes and what stays invariant.
- **Derivation**: let symbols emerge from visible geometry/data.
- **Consequence**: connect the abstraction to robot behavior.
- **Evidence**: show trace/result with source/status.
- **Recap**: compress existing ideas; introduce nothing new.

Continuity rules:
- Reuse the same point, ray, frame, robot, or token when its identity persists.
- Prefer morph, move, rotate, track, zoom, or transform over replacing the whole scene.
- A camera move represents a change of viewpoint; an object transform represents a change of state or interpretation.
- If narration changes topic, create a visual bridge before changing the scene.
