# Research -> production handoff

Create one compact brief using `templates/research_brief.md` or an existing project schema.

Required fields:
- exact paper/code/checkpoint identity and primary links;
- viewer question + prerequisite;
- one central mechanism with faithful pseudocode/data flow;
- minimal claim ledger with source locations and evidence labels;
- **Manim:** variables/equation/intervention to visualize;
- **Blender:** same sample/action as geometry or robot behavior;
- **experiment:** model/baseline/changed condition/reference/metric/feasibility;
- system interpretation: sensor/state input, action contract, execution rate if known;
- limitations, toy substitutions and unresolved implementation details.

If local inference is infeasible, specify a bounded toy experiment; never imply reproduction. The Director should consume this brief instead of rereading the full paper. YouTube metadata later consumes only verified claims, source links and simplification disclosures.
